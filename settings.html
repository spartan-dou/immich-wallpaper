Serveur Immich

Immich → Paramètres du compte → Clés API. Permissions : album.read, asset.read, asset.view, asset.download (et asset.update pour « Ajouter aux favoris »).
Connexion non chiffrée (http://) vers un serveur hors réseau local : le token et les photos circulent en clair. Préfère https://.
Le certificat présenté lors du test est mémorisé (empreinte SHA-256) : seul ce certificat sera accepté ensuite. S'il est renouvelé, reteste la connexion puis enregistre.

Albums

Teste la connexion pour afficher tes albums.

Affichage

Hors ligne : si Immich est injoignable (déplacement, VPN coupé…), la rotation continue avec les dernières photos téléchargées. 0 = désactivé.

Planification

Laisse les deux vides pour changer toute la journée. Une plage comme 22:00 → 07:00 passe par minuit.
Ces réglages ne concernent que les changements automatiques : « Image suivante » fonctionne toujours. Le changement se fait dès que la condition disparaît.
Le changement suivant est alors immédiat et ne dépend plus du réseau (utile au déverrouillage du PC).

Albums selon la saison ou l'heure

Quand une règle s'applique, ses albums remplacent ceux cochés plus haut (plusieurs règles en même temps : leurs albums sont réunis). Sinon, les albums habituels sont utilisés.

Légende et écran de verrouillage

Le fond d'écran lui-même n'est pas cliquable sous Windows : cette icône (ou un clic gauche sur l'icône près de l'horloge) ouvre la photo affichée.
Dans Windows : Paramètres → Personnalisation → Écran de verrouillage → « Image » (et non « Windows à la une »).

Mises à jour

Vérification au démarrage puis une fois par jour. Téléchargement depuis les releases GitHub du projet uniquement ; l'empreinte SHA256 détecte un fichier corrompu (les releases ne sont pas signées).
