Affichage

Hors ligne : si Immich est injoignable (déplacement, VPN coupé…), la rotation continue avec les dernières photos téléchargées. 0 = désactivé.

Légende et écran de verrouillage

Le fond d'écran lui-même n'est pas cliquable sous Windows : cette icône (ou un clic gauche sur l'icône près de l'horloge) ouvre la photo affichée.
Dans Windows : Paramètres → Personnalisation → Écran de verrouillage → « Image » (et non « Windows à la une »).
